🛒 Smart Grocery Shopping Assistant

An interactive grocery management application built with Python & Streamlit that helps users track pantry inventory, get recipe suggestions, manage budgets, and create shopping lists — all in one place.

                                                        🚀 Features


                                                  📦 Inventory Management
-> Add, edit, and delete pantry items

-> Track stock levels and expiry dates

-> Quick search: “Do I have rice?”

                                                  🍲 Recipe Suggestions
-> Integrated with Spoonacular API

-> Get personalized recipes based on pantry items

-> View recipe details, ingredients, and instructions directly inside the app

                                                   💰 Budget Planning
-> Track Planned vs Actual Spending

-> Animated progress bars for insights

-> Helps users control expenses

                                                    🛍 Shopping List
-> Create custom shopping lists

-> Estimate costs before purchase

-> Convert pantry shortages into a shopping list

                                                  🤖 Smart Assistant
-> Interactive helper for pantry & recipe queries

-> Natural language support for quick answers

                                                🔐 User Authentication
-> Secure Login/Signup system

-> Session handling for personalized experience

                                                 🎨 Modern UI
-> Inventory items displayed as interactive cards

-> Tab-wise organized dashboard

-> Smooth animations and professional design

                                                ☁️ Deployment
-> Deployed on Streamlit Cloud

-> Accessible via public shareable link

                                                🛠 Tech Stack
-> Frontend/UI: Streamlit

-> Backend: Python

-> Database: Session State + Local Persistence

-> APIs: Spoonacular (for recipes)

-> Libraries: Pandas, Requests, JSON, Plotly/Altair (for charts)

                                             🔑 Setup & Installation

            1. Clone the repo:
git clone https://github.com/your-username/smart-grocery-assistant.git

cd smart-grocery-assistant

            2. Install dependencies:
pip install -r requirements.txt

            3. Add your Spoonacular API key in config.py:
SPOONACULAR_KEYS = ["your_api_key_1", "your_api_key_2"]

            4. Run the app:
streamlit run app.py
